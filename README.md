## طريقة الإضافة على الآيفون (مُختبَرة)

جيت‌هب يرسل ملف `.ics` المباشر بنوع `text/plain`، فالآيفون يعامله كنص عادي
ولا يفتح التقويم. رابط الأرشيف المضغوط يرسله كمرفق حقيقي
(`Content-Disposition: attachment`) فيصل للجوال باسمه وامتداده الصحيحين:

    https://github.com/haljur/Hatem/archive/refs/heads/claude/jojo-exam-calendar-alerts-205yr7.zip

الخطوات: افتح الرابط في Safari ← ينزّل ملف مضغوط ← افتحه من تطبيق "الملفات"
← يفك الضغط لمجلد ← اضغط `jojo-exams.ics` بداخله ← يفتح التقويم.

إن لم يفتح الملف العربي، فبداخل نفس المجلد `jojo-exams-en.ics` بأحرف ASCII فقط
ونفس المواعيد والتنبيهات تمامًا.

## الإدخال اليدوي

فاختبارات الفاينل (3 تنبيهات) تحتاج حدثًا إضافيًا لتغطية التنبيه الثالث.
