## طريقة الإضافة على الآيفون

1. حمّل الملف `jojo-exams.ics` على الجوال.
2. اضغط عليه — يفتح تطبيق التقويم مباشرة.
3. اختر التقويم اللي تبي تضيف فيه، ثم "إضافة الكل" / Add All.
4. تأكد أن الإشعارات مفعّلة للتقويم من: الإعدادات ← الإشعارات ← التقويم.

الأحداث مسجّلة كأحداث يوم كامل (all-day) وبحالة "متفرّغ" حتى ما تأثر على جدولك.
