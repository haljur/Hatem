# محاكاة غرفة السينما المنزلية | Cinema Room 3D Simulation

محاكاة ثلاثية الأبعاد (Three.js) مبنية طبق الأصل على مخطط غرفة السينما العلوي،
وتُصوَّر من زاوية نظر إنسان واقف داخل الغرفة (ارتفاع العين ≈ 1.62 م).

## المقاسات المطبقة من المخطط

| العنصر | المقاس |
|---|---|
| أبعاد الغرفة | 5.22 م (عرض) × 5.53 م (طول) |
| الشاشة | 98 بوصة — 217 سم عرض |
| جدار التلفزيون (ألواح خشبية + إضاءة مخفية) | 330 سم |
| الكونسول السفلي | 270 × 38 سم، ارتفاع 33 سم |
| السريران السينمائيان | 125 سم عرض لكل سرير، مائلان قليلاً نحو الشاشة |
| مسافة المشاهدة من السرير | ≈ 2.8 – 3.3 م |
| صف الكراسي الخلفية | 4 كراسٍ جلدية، عرض الكرسي ≈ 62 سم |
| المنصة الخلفية | عمق 168 سم، ارتفاع 25 سم |
| مسافة المشاهدة من الكراسي الخلفية | ≈ 4.2 – 4.8 م |
| ممر الدخول أمام الباب | ≈ 90 سم |
| الدرج الجانبي المضاء | 3 درجات للوصول للمنصة الخلفية |
| الستارة الخلفية | كاملة من السقف إلى الأرض بعرض الجدار |

عناصر إضافية من المخطط: لوحات سينمائية بإضاءة مخفية خلف الإطارات على الجدران
الجانبية، إضاءة محيطية مخفية (سقف + تحت الكونسول + حافة المنصة + أنف الدرجات)،
تشطيبات داكنة وملمس قماشي ناعم.

## التشغيل

```bash
npm install
python3 -m http.server 8123   # من داخل هذا المجلد
# ثم افتح http://localhost:8123/index.html?cam=1  (زوايا الكاميرا: 1-4)
node render.mjs               # يلتقط اللقطات الأربع تلقائياً
```

- `cam=1` واقف عند الباب
- `cam=2` واقف على المنصة الخلفية خلف الكراسي (لقطة الشاشة الرئيسية)
- `cam=3` الزاوية الأمامية اليسرى نحو الخلف
- `cam=4` الممر الجانبي نحو جدار الشاشة
